## ✨ Features

- 🐍 Classic Snake gameplay.
- 🍎 Collect apples to increase your score.
- 🧮 Real-time score display.
- 🎨 Custom snake and apple sprites.
- 🪵 Wooden-style game boundary.
- 🎮 Simple arcade-inspired gameplay.
